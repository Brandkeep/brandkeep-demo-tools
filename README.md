# Brand Keep Demo Tools

A small collection of browser-only examples inspired by the kinds of planning work Brand Keep does. These are independent sample projects, not client work, case studies, or production services.

## Demos

- [Campaign Brief Builder](campaign-brief/) — turn planning notes into a structured first-draft brief. The form stays in your browser.
- [Website Launch Checklist](launch-checklist/) — review content, navigation, technical basics, search setup, and approvals. Progress is saved in local browser storage.
- [Media Budget Planner](media-budget-planner/) — calculate a percentage-based channel split in a selected currency. It does not convert currencies or recommend spending.

## Run locally

Open a demo folder's index.html in a modern browser. No build step, external package, or server is required.

## Privacy and scope

These demos do not send form entries or budget figures to a server. Browser-only storage is used by the checklist so progress can persist on the same device. The tools are examples for discussion and should be adapted and reviewed before operational use.
